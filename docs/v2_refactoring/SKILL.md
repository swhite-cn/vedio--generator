# VideoForge 前端重构 Skill

## 0. 适用范围与原则

VideoForge 是本地视频生成工作流平台（将演进为通用 Agent 工作流平台）。本 skill 指导 AI 将现有前端重构为与定稿设计稿一致的实现。

核心原则：
1. **镜头级（shot-level）是一等公民**：所有 UI 围绕「一句一镜」组织，不使用场景/段落级粗放表达。
2. **深色开发者工具风格**：对标 Linear / Vercel，克制、密度适中、无渐变堆叠、无 emoji。
3. **先令牌后组件**：所有颜色、字号、圆角必须来自第 1 节令牌，禁止散落魔法值。
4. **交互即流水线**：用户能随时查看每个阶段的产物、从失败阶段重跑、在镜头级重生成。

## 1. 设计令牌（必须落为 CSS 变量 / theme tokens）

### 1.1 界面主题（深色，唯一主题）

```css
:root {
  /* 背景层级：页面 < 侧栏 < 卡片 < 内嵌 */
  --bg:        #0B0E13;  /* 页面背景 */
  --deep:      #07090D;  /* 侧栏背景 */
  --surface:   #141821;  /* 卡片、输入框 */
  --surface-2: #1B2130;  /* 悬停/选中卡片、表头 */
  --inset:     #0D1117;  /* 代码块、JSON、内嵌区域 */
  --border:    #262E3D;  /* 常规描边 */
  --border-soft:#1D2430; /* 分隔线、弱描边 */

  /* 文本三级 */
  --text:      #EDF1F7;
  --text-sec:  #97A3B4;
  --text-ter:  #626D7E;

  /* 品牌主色（唯一强调色） */
  --accent:      #7B6CFF;
  --accent-soft: #232041;

  /* 语义色：前景 / 软底配对使用 */
  --success: #3DD68C;  --success-soft: #122B20;
  --danger:  #F26D6D;  --danger-soft:  #331B1F;
  --warning: #F5B14C;  --warning-soft: #33270F;
  --info:    #56B3F5;  --info-soft:    #12283B;
  --teal:    #3BD5B0;  --teal-soft:    #0F2B26;
}
```

### 1.2 成片视觉令牌（仅用于视频预览、镜头画布 mock）

这些是流水线产出视频的主题色（来自参考科普片），只出现在预览画布、主题 token 展示等处，**不得污染界面主题**：

```
片文字 #E5E0D5 · 片背景 #111310 · 强调下划线 #F1E21D
辅助 #B33630 / #3BD5B0 / #4904F5
```

### 1.3 字体与排版

- 正文/界面：系统无衬线栈（`PingFang SC, Microsoft YaHei, system-ui`）。
- 等宽：`JetBrains Mono`，**仅用于** Run ID、时间码、文件名、JSON、镜头号（#21）、cue 计数等技术性内容。
- 字号阶梯：10.5（辅助标注）/ 11.5–12（次级正文）/ 12.5–13（正文）/ 14–16（卡片标题）/ 18–20（页标题）。正文行高 1.5。
- 字重：常规 400；标题与主按钮 600。不使用 300 或 800。

### 1.4 圆角 / 间距 / 描边

- 圆角：卡片 10–12px，按钮/输入 8px，标签 pill 全圆角（h/2），头像/状态点全圆。
- 描边统一 1px；不使用 2px 以上描边。
- 卡片内边距 20–24px；卡片间距 16–24px；栅格基于 4px。
- 阴影仅用于模态框，一处即可，不使用彩色投影。
- **禁止使用带透明通道的叠色实现遮罩/阴影**（如 `rgba` 叠层在某些渲染链路出问题），遮罩用纯色 + `opacity: 0.8`。

## 2. 布局壳（App Shell）

所有登录后页面共用同一壳，尺寸基于 1440×900 设计稿等比实现：

```
┌──────────┬────────────────────────────────────────┐
│ 侧栏 196px│ 顶栏 56px（面包屑 / 全局搜索 / 通知 / 头像）│
│ --deep   ├────────────────────────────────────────┤
│          │ 内容区：padding 28px，最大宽不限          │
└──────────┴────────────────────────────────────────┘
```

### 2.1 侧栏

- Logo 区：30×30 主色圆角方块（`fas:clapperboard` 白图标）+「VideoForge」16px 600。
- 导航 5 项，顺序固定：**能力中心 / 项目 / 素材库 / 组件库 / 管理**，图标依次为 `grip / folder-open / images / cubes / gear`。
- 导航项高 38px、间距 6px；选中态 = `--surface-2` 底 + 左侧 3×20 主色指示条 + 图标/文字点亮（主色图标、`--text` 文字）；未选中图标 `--text-ter`、文字 `--text-sec`。
- 底部用户卡：头像 32px 圆形（`--accent-soft` 底 + 主色首字母）+ 姓名 12px 600 + 角色 10.5px `--text-ter`。

### 2.2 顶栏

- 左侧面包屑 12.5px `--text-ter`，层级用「/」分隔（如 `项目 / video-test / Runs`）。
- 右侧：全局搜索框（240×34，placeholder「搜索项目、素材、组件」）、通知铃（带 7px 红点）、头像 32px。

## 3. 组件配方

### 3.1 按钮（4 种变体）

| 变体 | 底 | 字 | 描边 | 用途 |
|---|---|---|---|---|
| accent | `--accent` | #FFF 600 | 无 | 主操作：发起 Run、创建项目、登录 |
| ghost | 透明 | `--text-sec` | `--border` | 次操作：返回、取消、上一步 |
| danger | `--danger-soft` | `--danger` 600 | danger 20% | 重跑失败阶段等破坏性/警示操作 |
| success | `--success-soft` | `--success` 600 | success 17% | 通过/确认类 |

高度：常规 36–38px；模态内主按钮 40px。图标按钮 = 图标 + 文字水平居中，图标与文字间距 8px。

### 3.2 状态 pill

全圆角，10.5px，软底 + 同色前景：已完成=success、进行中=accent、失败=danger、排队/待执行=`--surface-2`+`--text-ter`、风格锚=teal。可叠加旋转 loader（进行中）或勾选图标。

### 3.3 卡片

`--surface` 底 + `--border-soft` 描边 + 12px 圆角。标题行 = 图标/名称 + 右侧 meta（`--text-ter` 11.5px）。卡片内次级分区用 `--inset` 底 + 8px 圆角。

### 3.4 表单

- 输入框：`--surface` 底、`--border` 描边、8px 圆角、高 40px；label 12px `--text-sec`，必填项加红色 `*`。
- 下拉与输入同样式，右侧 chevron；说明性 hint 用 11px `--text-ter` + 等宽路径（如 `config/profiles/*.yaml`）。
- 上传区：虚线/描边盒 + 居中图标 + 说明文字（如风格锚参考图上传）。

### 3.5 表格

表头 `--surface-2` 底、11.5px `--text-ter`；行高 44px，行间 1px `--border-soft` 分隔；技术列（ID、时长、镜头数）用等宽；状态列用 pill。不出现竖向网格线。

### 3.6 模态框

页面遮罩：纯色 `--deep` + `opacity 0.8`。模态体 `--surface` 底 + 12px 圆角 + 单层深色阴影。右上角 `×` 关闭。宽 560px 左右， footer 右对齐按钮组（ghost + accent）。

### 3.7 流水线阶段列表（复用度最高）

垂直步骤条：22px 圆形节点（ok=success 底+✓ / fail=danger 底+✕ / 进行中=accent 描边+loader / 待执行=`--surface-2`+序号），节点间 1px 竖线连接。行内：阶段名 13px + 右侧结果 meta（如 `已完成 · 78 shots`、`进行中 · 62%`）。失败行整行 `--danger-soft` 底高亮。

### 3.8 代码 / JSON 块

`--inset` 底 + 8px 圆角 + JetBrains Mono 12px；键 `--info`、字符串 `--success`、错误行 `--danger`；右上角复制按钮。错误 banner 用 `--danger-soft` 全宽条 + 左侧 ⓘ 图标 + 错误码等宽高亮 + 右侧操作按钮（如「从配音阶段重跑」）。

### 3.9 分镜时间轴（核心复合组件）

- 三轨道自上而下：**画面 / 字幕 / BGM**，各 36–44px 高，左侧轨道名 64px。
- 镜头块 = 画面轨上的圆角块（`--surface-2` 底，选中 `--accent-soft` + 主色描边），块内等宽标注镜头号（#21）与时长。
- 字幕轨块显示 cue 文本截断；BGM 轨为连续长条（teal）。
- 播放头：1.5px 红色竖线 + 顶部时间码（等宽 10.5px）；窗口默认显示 60s，可缩放。
- 画布区 16:9，`#111310` 底，叠放：左上章节角标（CH.03）、中部屏幕文字（`#E5E0D5`，强调词 `#F1E21D` 下划线）、底部 6% 处字幕条（白字黑边样式用深色底条模拟）、右下来源标签。
- Inspector（右侧 292px）：口播文本、cue 时间戳（等宽）、屏幕文字、组件模板选择、素材绑定（风格锚 badge）、转场类型、主题 token 色板、底部「重生成此镜头」（accent）+「预览动效」（ghost）。

### 3.10 质检门禁列表

每行 = 状态圆点（✓/✕）+ 检查项名 + 右侧结果描述（失败项 `--danger` 并标注镜头号，如 `2 处超 18 字: #34 #57`）。五项固定：静帧检测 / 字幕溢出 / 来源标签 / 画面对比度 / 动效时长。卡片头部右侧汇总 pill（`N 项待处理`，warning）。

## 5. 数据模型 → UI 映射（不可违背）

1. `scenes[].shots[]`：项目统计一律用镜头数（如「78 镜头」），禁止用「场景数」概括。
2. 配音产物为逐句时间戳 `cues[]`：工具调用产物数显示 `98 cues`；请求参数含 `"timestamps": true`。
3. 字幕是独立 ASS 轨道：时间轴单独一轨；规范=白字黑边、底部 6%、单行 ≤18 字；超 18 字触发质检「字幕溢出」。
4. 布局组件 7 类，LLM 只选模板填参数：组件库与 Inspector 中体现为「模板选择 + 参数」，无自由 HTML 输入。
5. 动效时长固定 0.3–0.8s，不做时间轴拉伸；质检含「动效时长」项。
6. 风格锚：跨镜头同一符号复用同一资产 + seed（质子=红球等）；镜头重生成沿用 seed，仅替换本镜头素材，UI 需明确提示不影响其余镜头。
7. 转场三型：硬切 / 黑卡字卡 / 短淡化；Inspector 中转场为枚举选择。
8. 合成含独立 BGM 轨：时间轴第三轨。
9. 质检门禁四项硬指标：静帧检测、字幕溢出、来源标签缺失、对比度（阈值 7.2:1），失败必须定位到镜头号。

## 6. 交互规则

- 失败优先：任何页面出现失败，顶部全宽 banner + 明确重跑入口（粒度=阶段）。
- 一切产物可溯源：文件、镜头、cue 均可点击定位；资产卡片显示绑定镜头数。
- 镜头级重生成是核心闭环：对话页与分镜编辑器都要有入口，且提示 seed 锚定行为。
- 空态不堆装饰：用一行说明 + 主操作按钮即可。

## 7. Do / Don't

**Do**
- 所有取值引用第 1 节令牌；新语义先加令牌再用。
- 技术性文本一律 JetBrains Mono。
- 保持密度：信息优先，装饰为零。

**Don't**
- 不用浅色主题、不用渐变背景、不用 emoji、不用玻璃拟态。
- 不自创第 8 种布局组件类型、第 4 种转场。
- 不把成片主题色（#F1E21D 等）用于界面控件。
- 不用 rgba 叠色做遮罩/阴影（用纯色 + opacity）。

## 8. 验收清单（重构完成后逐项核对）

- [ ] 全部颜色/圆角/字号可在令牌表中找到来源
- [ ] 5 项导航与顶栏在所有登录后页面一致
- [ ] 10 个页面结构与第 4 节一一对应
- [ ] 镜头数、cues、ASS、质检门禁、风格锚在各页面文案中正确出现
- [ ] 状态体系（4 种 pill + 阶段节点 4 态）无自造变体
- [ ] 与 videoforge-ui-redesign 设计稿逐页视觉比对通过
